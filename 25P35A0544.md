**Git commands**
- git checkout -b branchname [Create a new branch and switch to that branch]
- git branch [list all the branches and indicate the current branch with green color]
- git add . or filename
- git clone path [used to clone the entire repository]
- git remote add origin path [connects local repository to a remove server]

**Purpose of Github**
- it is a cloud platform where the developers store, manage, track using git
- allows multiple people work on a project
- provides backup for local git repository

**Benefit of using branches**
- Branches allow us to work simultaneously on a project without effecting the main project
