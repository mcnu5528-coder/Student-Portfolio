## Three Git Commands I Learned
1. `git status` - shows which files are new, modified or staged.
2. `git add <file>` - stages changes for the next commit.
3. `git commit -m "message"` - saves the staged changes in the local repository.

## Purpose of GitHub
GitHub hosts Git repositories online so people can store code, collaborate, review changes and share projects.

## One Benefit of Branches
Branches let me work on changes separately without affecting the main branch.
