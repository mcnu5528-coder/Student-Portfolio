## Three Git Commands I Learned
1. `git status` — inspects the working tree and staging area to show modified, untracked, or staged files.
2. `git add <file>` — moves changes from the working directory into the Git staging area in preparation for a commit.
3. `git commit -m "message"` — records staged snapshot changes permanently into the repository history with a meaningful message.

## Purpose of GitHub
GitHub is an online hosting platform for Git repositories that enables developers to store, manage, and track versions of their code in the cloud, while providing collaborative tools such as Pull Requests, code reviews, issue tracking, and automated CI/CD workflows.

## One Benefit of Branches
Branches provide isolated workspaces where developers can safely build features, fix bugs, or experiment without affecting the production stability of the `main` branch until the code has been tested, reviewed, and merged.
