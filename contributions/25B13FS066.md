## Three Git Commands and Their Purposes

1. `git init` — Creates a new Git repository.
2. `git add .` — Stages changes for the next commit.
3. `git commit -m "message"` — Records staged changes in the local repository.

## Purpose of GitHub

GitHub is an online platform for hosting Git repositories. It helps people share code, collaborate, review changes, and manage projects.

## One Benefit of Using Branches

Branches allow developers to work on new features separately without directly changing the main branch.
