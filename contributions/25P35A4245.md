\## Three Git Commands I Learned



1\. `git add` — Stages changes for a commit.

2\. `git commit -m "message"` — Records staged changes.

3\. `git push` — Uploads local commits to a remote repository.



\## Purpose of GitHub



GitHub hosts repositories online and helps developers share code, track changes, and collaborate on projects.



\## One Benefit of Using Branches



Branches allow developers to work on features separately without directly changing the main branch until the work is reviewed and merged.
