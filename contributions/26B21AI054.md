## Three Git Commands

### 1. git status
Displays the current branch and shows modified, staged, and untracked files.

### 2. git add .
Stages the current directory's changes so they can be included in the next commit. Review the files before running this command.

### 3. git commit -m "Update portfolio documentation"
Records the staged changes in the local Git repository with a descriptive message.

## Purpose of GitHub

GitHub is an online platform for hosting Git repositories. It allows developers to store code, track changes, collaborate with others, review contributions, and share projects.

## One Benefit of Using Branches

Branches allow developers to make changes separately from the main branch. They can test and review their work before merging it into the main project.
