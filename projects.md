## Project 1: CertiHub — AI-Powered Credential Verification & Career Intelligence Platform
- **Problem:** Manual certificate verification and skill assessment are slow, cumbersome, and susceptible to document manipulation in recruitment and admissions.
- **Solution:** An AI-driven platform that automates document OCR, validates credential metadata, extracts key competencies, and matches candidate profiles to career benchmarks.
- **Technologies:** Python, FastAPI, React, PyTorch, Tesseract OCR, PostgreSQL
- **My contribution:** Developed the automated document processing pipeline, OCR feature extraction module, and RESTful API endpoints for candidate intelligence scoring.
- **What I learned:** Machine learning pipeline deployment, REST API integration, and full-stack software development workflows during my summer internship at Technical Hub.
- **Possible improvement:** Integrate cryptographic hash verification on a distributed ledger to guarantee certificate authenticity.

## Project 2: Celebration Event Planner
- **Problem:** Organizing institutional celebrations and private events often suffers from uncoordinated scheduling, chaotic budget tracking, and fragmented vendor communication.
- **Solution:** A modern, interactive web application featuring dynamic event schedules, budget calculators, vendor management directories, and live guest lists.
- **Technologies:** HTML5, CSS3, JavaScript, LocalStorage, Git, GitHub Pages
- **My contribution:** Designed the responsive user interface, implemented dynamic scheduling logic and interactive expense tracking in vanilla JavaScript.
- **What I learned:** Responsive CSS design (Flexbox and CSS Grid), asynchronous DOM manipulation, and version-controlled feature delivery.
- **Possible improvement:** Implement real-time multi-user synchronization and automated notification reminders using WebSockets.
